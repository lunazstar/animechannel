# Nintendo 3DS Anime Channel Revival

This is a project to bring back the old forgotten app of Anime Channel back to life, with full on server side and custom catalog support
This mainly works using Luma RomFS patches, which modify certain redirections to your servers

### How does this work?
Simply by redirecting certain hardcoded URLs to whatever you desire, in our case, our hardcoded URL is a Nintendo official one:
```
lightning-dev.mobiclip.com/front/service
```
To something less proprietary and that we can work with:

```
192.168.1.1/vidcatalog.json
```

Yeah, anime channel just reads a json table with the thumbnails and episodes, simple?
Its just a Nintendo Video reskin, same player and everything
